# idxMaker (v0.10)

`idxMaker` は、PDF内のテキスト位置と正規表現パターンを照合し、**PDFへ「しおり（目次）」を自動で埋め込む**ためのデスクトップアプリケーションです。
税制改正の解説書や、行政の事務運営指針といった、規則的な階層構造（第1章、第1節、(1) など）を持つ長編PDFの目次整理を強力に自動化します。

---

## 🌟 主な機能

* **直感的なパターン構築**: 難しい正規表現を直接書かなくても、ドロップダウンから「第」「半角数字123」「章」などを選ぶだけで簡単に階層ルールを構築可能。
* **改行を跨がない安全な空白処理**: 「末尾に空白」チェックを入れることで、PDF特有の特殊空白（ノーブレークスペースや全角空白）を次の行を巻き込まずに安全に検知。
* **正確なページ内リンク**: テキストボックスの左上座標（X, Y）をミリ単位で計算し、しおりをクリックした際に該当タイトルへピタッとジャンプするリンクを生成。
* **設定ファイルの多重管理**: プロジェクトやPDFの書式ごとに、しおりの抽出パターンを個別の `.json` ファイルとして読み込み・別名保存が可能。
* **階層の自動補正**: 万が一途中の階層（レベル）が飛んでいた場合、自動でダミーしおりを挟んでPDFの目次構造エラーを防止。

---

## 🛠 動作環境

* **Python 3.8+**
* 依存外部ライブラリ:
  * `PyMuPDF` (しおりの高速書き込み用)
  * `pdfminer.six` (高精度なレイアウト解析・座標取得用)

### インストール方法
```bash
pip install pymupdf pdfminer.six
```

## 🚀 使い方

1. `idxMaker.py` を実行すると、設定ダイアログが起動します。
2. **対象のPDFファイル** を「参照...」ボタンから選択します。
3. **ページ範囲** を指定します（終了ページを `0` にすると最後まで処理します）。
4. 各行に、抽出したい目次のルール（最大10階層）を設定します。
   * **例: 第1章のタイトルの場合**
     * 階層: `1` | 前: `第` | 中: `半角数字123` | 後: `章` | 末尾に空白: `ON`
5. 必要に応じて「別名で保存...」から設定を保存します。
6. **「実行」** ボタンをクリックすると処理が始まり、同じフォルダに `output_[元のファイル名].pdf` が自動生成されます。

## 📝 パターンマッピング仕様（一部抜粋）

ドロップダウンで選択した日本語表記は、実行時に以下の正規表現コードへ自動変換されます。

| 選択肢 (UI表示) | 内部正規表現コード | 対象となる文字の例 |
| :--- | :--- | :--- |
| **半角数字123** | `[0-9]+` | 1, 23, 105 |
| **漢数字一二三** | `[一二三四五六七八九十百千万...]+` | 第一, 十五, 附則 |
| **ローマ数字ⅠⅡⅢ** | `[ⅠⅡⅢⅣⅤⅥⅦⅧⅨⅩⅫ]+` | Ⅰ, Ⅱ, Ⅺ |
| **丸数字①②③** | `[①-⑳]` | ①, ⑤, ⑳ |
| **末尾に空白 (ON)** | `[^\S\r\n]+` | 行末の全角・半角スペース、特殊空白（改行は除く） |

## ⚠️ 注意事項

* **上書きについて**: 処理が完了すると、元のPDFではなく `output_` という接頭辞がついた新しいPDFファイルが書き出されます。
* **テキスト化されていないPDF**: スキャンした画像だけのPDFなど、内部にテキストレイアウト情報を持っていないPDFからはしおりを抽出できません。事前にOCR処理等を行ってください。
