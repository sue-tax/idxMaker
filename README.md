* * # PDF Index & Link Automation Tools (idxMaker Suite)

    PDFのドキュメント構造を解析し、**「左側ナビゲーション用のしおり（アウトライン）の自動埋め込み」**および**「目次ページ内から本文への相互ハイパーリンク自動付与」**を行うPythonスクリプト群です。
    長編の報告書、税制改正の解説書、問答集（FAQ形式）、行政の事務運営指針などのPDF整理を強力に自動化します。

    ---
    ## 新ツール　linkMakerAll

* linkMaker の改良版（目次のページの判定、本文の判定を強化）

    ## 📦 収録ツール一覧

    本リポジトリには、PDFのレイアウトや目的に応じた3つのスクリプトが収録されています。

    | ツール名                | 主な機能・役割                                               | アプローチ特徴                                               |
    | :---------------------- | :----------------------------------------------------------- | :----------------------------------------------------------- |
    | **1. idxMaker (GUI版)** | PDF全体に**左側ナビゲーションしおり（階層構造）**を自動追加する。 | Tkinter GUIダイアログによるルール編成、JSON設定管理。        |
    | **2. linkMaker**        | 目次ページ内のタイトルから**本文への内部リンク**を自動で貼る。 | リーダー記号（点々）の密度から目次終了ページを完全自動特定。 |
    | **3. linkMakerTenten**  | 複雑なレイアウトの目次から**本文への内部リンク**を自動で貼る。 | 2段組等の左右テキストを物理座標(Y軸)基準で1行に並び替えて結合。 |

    ---

    ## 🛠 動作環境・プリリクエスト

    * **Python 3.8+**
    * **依存外部ライブラリ**:
      * `PyMuPDF (fitz)` : PDFへの高速なしおり・内部リンク書き込みに使用。
      * `pdfminer.six` : 高精度な文字列抽出およびミリ単位の構造・座標解析に使用（※idxMakerのみで使用）。

    ### インストールコマンド
    ```bash
    pip install pymupdf pdfminer.six
    ```

    ## 🚀 各ツールの詳細と使い方

    ### 1. idxMaker (GUI版)
    GUIで抽出条件を設定し、PDF内に最大10階層のアウトライン目次を構成します。

    #### 特徴:
    * 難しい正規表現を知らなくても、ドロップダウンから「第」「半角数字123」「章」などを選ぶだけでルールを自動構築。
    * 「末尾に空白」チェックを入れると、改行を跨がない安全な空白処理（`[^\S\r\n]+`）を裏側でドッキング。
    * プロジェクトごとに設定を `.json` ファイルとして別名保存・読み込み管理が可能。
    * 階層構造が不正（レベル1の次にレベル3が来るなど）な場合、自動で `(ダミー)` しおりを生成して構造エラーを防止。

    #### 使用方法:
    1. スクリプトを実行すると、設定ダイアログが起動します。
    2. 対象PDF、ページ範囲、各階層の正規表現ルールを入力し「実行」をクリック。
    3. 処理完了後、`output_[元ファイル名].pdf` が出力されます。

    ---

    ### 2. linkMaker
    「問1 ……… 15」のようなFAQ形式の目次を探知し、目次から本文へジャンプするリンクを一括生成します。

    #### 特徴:
    * リーダー記号（「・」や「.」）が3回以上連続する行が1ページ内に3行以上あるか否かで、**目次の最終ページを完全自動判定**。
    * 開始行（デフォルトは `"問"` から始まる行）を基準に、タイトルから末尾のページ数までをスマートに補足。

    #### 使用方法:
    1. スクリプトを実行し、コンソールにPDFのパスを入力します。
    2. 自動で目次範囲が特定され、リンクが付与された `[元ファイル名]_linked.pdf` が出力されます。

    ---

    ### 3. linkMakerTenten (レイアウト補正版)
    2段組レイアウトや、ノンブル（ページ番号単体行）が紛れ込む、より複雑なPDF目次に対応します。

    #### 特徴:
    * **Y軸座標許容判定（Y_TOLERANCE = 4）**: 左右に分かれて抽出されてしまうテキスト文字列を、同じ高さにあるものは物理的に1行として結合ソート。
    * **ノンブル行ガード機能**: 単なるページ番号表示（例: `"- 95 -"`、`"95"`、`"— 95 —"`) の不要な独立行を、リンク生成対象のバッファから完全に除外してスキップ。
    * 各種リーダー記号（`· .  ･ ‥ … - * ・`）の後に数字で終わる複雑な目次行を確実にキャッチする柔軟な正規表現を搭載。
    * 範囲指定（`toc_start_page` / `toc_end_page`）と、本文の物理ページ位置のズレを修正する `page_offset` をコード上で手動調整可能。

    #### 💡 主な活用事例：日本標準産業分類への適応
    総務省が公開している「**日本標準産業分類**」の解説PDFのように、大分類・中分類が2段組で記載され、かつページ末尾に無数のリーダー記号（点々）とノンブルが並ぶ**極めて難解なレイアウトを持つ公的文書**の電子化・ハイパーリンク紐付けに絶大な効果を発揮します。

    #### 使用方法:
    1. 事前にスクリプト内の「★今回のPDF専用の設定」値（開始・終了ページ、オフセット値）を、処理したいPDFに合わせて書き換えます。
    2. スクリプトを実行し、PDF의 パスを入力すると、目次テキストから本文へのリンクが付与された `[元ファイル名]_linked.pdf` が出力されます。

    ## 📝 内部正規表現・マッピング仕様（idxMaker）

    GUI版の `CONVERT_MAP` では、以下の日本語定義が本物の正規表現へと自動コンパイルされます。

    | UI表示名           | 変換される正規表現                 | マッチング対象例       |
    | :----------------- | :--------------------------------- | :--------------------- |
    | **半角数字123**    | `[0-9]+`                           | `1`, `24`, `100`       |
    | **全角数字１２著** | `[０-９]+`                         | `１`, `５２`           |
    | **漢数字一二三**   | `[一二三四五六七八九十百千万...]+` | `一`, `三十五`, `十一` |
    | **ローマ数字ⅠⅡⅢ**  | `[ⅠⅡⅢⅣⅤⅥⅦⅧⅨⅩⅫ]+`                   | `Ⅰ`, `Ⅳ`, `Ⅻ`          |
    | **丸数字①②③**      | `[①-⑳]`                            | `①`, `⑩`               |
    | **附則**           | `附[\s\u2003\u200b]+則`            | `附則`, `附  則`       |
    | **条..**           | `条\S*`                            | `条`, `条の二`         |

    ## ⚠️ 注意事項

    * **OCR未実施のPDFについて**: スキャンしただけの「画像化されたPDF」からはテキストや座標を抽出できません。あらかじめ文字認識（OCR）済みのPDFをご用意ください。
    * **元のファイルのバックアップ**: 本ツールはすべて別名で新規PDFを出力する安全設計ですが、重要なドキュメントを処理する際は事前にバックアップを推奨します。
